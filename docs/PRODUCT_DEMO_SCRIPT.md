## 📝 Production Notes

### Timing
- **Total duration**: 2:00
- **Pacing**: Confident, professional, not rushed
- **Tone**: Solution-oriented, not fear-based

### Visual Requirements
- Factory footage (can use stock or own)
- Screen recording of actual product
- Clean transitions between sections
- Lower-third graphics for key stats

### Music
- Upbeat, professional background
- Lower volume during narration
- Slightly louder during transitions

### Key Metrics to Display
- "$20B annual MSD cost"
- "88.6% risk detection accuracy"
- "30+ FPS real-time tracking"
- "2-hour ROI per camera"

### Recording Tips
1. Use 1080p or 4K screen recording
2. Show actual product, not mockups
3. Include real alert notifications
4. Show PDF report download
5. End with clear CTA and URL
